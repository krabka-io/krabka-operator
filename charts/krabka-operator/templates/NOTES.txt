This chart installed the CRDs from its own crds/ directory. Helm creates them
on install and leaves them alone on upgrade. After an upgrade that changes a
schema, apply them by hand from the same chart you upgraded with:

  helm pull CHART --version {{ .Chart.Version }} --untar --untardir /tmp/{{ .Chart.Name }}-crds
  kubectl apply -f /tmp/{{ .Chart.Name }}-crds/{{ .Chart.Name }}/crds

Replace CHART with the reference you gave to `helm upgrade`. If that reference
is a directory on disk, skip `helm pull` and apply that directory's crds/.
